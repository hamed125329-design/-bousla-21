# موقع بيع كتاب "البوصلة" (صفحة بسيطة)

هذه الملفات تتيح لك صفحة ثابتة بسيطة لعرض كتابك "البوصلة" وزر "اشترِ عبر WhatsApp" الذي يفتح محادثة جاهزة مع رقمك.

محتويات المجلد:
- index.html — الصفحة الرئيسية.
- styles.css — أنماط CSS بسيطة.
- script.js — بناء رسالة WhatsApp وفتح الرابط.
- README.md — تعليمات النشر.

كيف تستخدمها
1) نشر مباشر في هذا الريبو: تم إضافة الملفات في الفرع main.
2) يمكنك نشر الموقع مجانًا على Vercel أو GitHub Pages:
   - Vercel: تفضيله للنشر السهل (مجاني للخطط الأساسية). سجّل في vercel.com واربط الريبو ثم اضغط Deploy.
   - GitHub Pages: يتطلب أن يكون المستودع Public لعرضه مجانًا.

نصائح أمان:
- الطريقة المتبعة تفترض أن الدفع يتم يدويًا عبر WhatsApp. بعد استلام المبلغ، أرسل الكتاب للعميل عبر WhatsApp بنفسك.
- إن كان الملف موجودًا في الريبو وترغب أن يبقى خاصًا، حوّل الريبو إلى Private من إعدادات الريبو في GitHub.

تعديل المحتوى:
- لتغيير النص، السعر، أو رقم الواتساب، حدّث المتغيرات في script.js أو عدّل النصوص في index.html.

لو تبي أساعد أنشر الموقع على Vercel مجانًا، قل لي وسأرشدك خطوة بخطوة.
